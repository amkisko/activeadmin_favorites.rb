# Release 0.2.0

## Decisions

- Cut 0.2.0 as a minor. GraphQL Favorites exposure, create ownership, and `config.graphql` opt-out are a new public surface when GraphQL is present on the admin namespace. Skip RFC: opt-in only when GraphQL is already loaded; hosts can disable with `config.graphql = false`.
- Keep CHANGELOG and README free of sibling product names; describe GraphQL outcomes only.
- Hosts opt out with `ActiveAdmin::Favorites.config.graphql = false`. Skipping the `graphql` block alone is not enough: the namespace default still enables resources, so opt-out sets `graphql.enabled = false`.

## Effects

- CHANGELOG and `VERSION` set to 0.2.0.
- Engineering draft: `docs/changelogs/20261116094117_e2e-playwright-graphql.md`.
- `config.graphql` defaults to true; false disables the Favorites GraphQL surface.

## Next

- Commit feature work and release notes, then tag and publish with `make release`.
