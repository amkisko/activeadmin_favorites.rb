# Release 0.1.6

## Participants

Andrei Makarov (@amkisko)

## Decisions

- Cut 0.1.6 as a patch. Engine HTML head links `personalization_menu` and the path helper are install wiring for the stylesheet shipped in 0.1.5, not a new product contract. Skip RFC.
- Product CHANGELOG names the head link and the absolute path helper for Tailwind CLI concatenate hosts.
- Hosts that added a manual `stylesheet_link_tag` for this sheet can drop the duplicate after upgrading.

## Effects

- `lib/activeadmin/favorites/version.rb` is 0.1.6.
- CHANGELOG.md 0.1.6 (2026-10-27) holds the head link and path helper bullets.
- Gemfile.lock and appraisal lockfiles pin the path gem at 0.1.6.
- `make release` remains the publish path: clean tree, gem build, gem push.
