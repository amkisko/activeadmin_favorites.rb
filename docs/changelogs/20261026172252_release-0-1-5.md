# Release 0.1.5

## Participants

Andrei Makarov (@amkisko)

## Decisions

- Cut 0.1.5 as a patch. Scrollable personalization menu markup, Stimulus BEM classes, and the shipped stylesheet are a layout fix for the existing cogwheel UI, not a new contract. Skip RFC.
- Product CHANGELOG names the viewport behavior and the CSS import hosts need.
- Hosts that overrode `_personalization_trigger.html.erb` and the personalization Stimulus controller only for this layout can drop those overrides after upgrading and importing the stylesheet.

## Effects

- `lib/activeadmin/favorites/version.rb` is 0.1.5.
- CHANGELOG.md 0.1.5 (2026-10-26) holds the menu scroll and stylesheet bullets.
- Gemfile.lock and appraisal lockfiles pin the path gem at 0.1.5.
- `make release` remains the publish path: clean tree, gem build, gem push.
