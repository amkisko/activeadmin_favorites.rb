# Release 0.1.4

## Decisions

- Cut 0.1.4 as a patch. Lens catalog JSON embedding and view path order are a bugfix of column and panel personalization, not a new contract. Skip RFC.
- Product CHANGELOG keeps the 0.1.4 bullet already cut for this release.
- Hosts that overrode _lens_catalog_data.html.erb only for this escape can drop that override after upgrading.
- Relock crass to 1.0.8 and ransack to 4.4.4 so make release passes bundler-audit. Stay on the ransack 4.4 line. An update without --patch resolved 6.0.1 because activeadmin allows ransack >= 4.0.
- Leave crass and ransack off the gemspec. This release does not pin them for host apps.

## Effects

- lib/activeadmin/favorites/version.rb is 0.1.4.
- CHANGELOG.md 0.1.4 (2026-10-26) holds the lens catalog bullet.
- Gemfile.lock and appraisal lockfiles pin the path gem at 0.1.4, crass at 1.0.8, and ransack at 4.4.4.
- bundler-audit check --update on Gemfile.lock and the three appraisal locks reported no vulnerabilities. ruby-advisory-db commit 04bbdaed, last updated 2026-10-26 09:56:27 -0400.
- make release remains the publish path: clean tree, gem build, gem push.
